# Profil: Claude (Claude Code) — `model: claude`

**Mocne strony:** długi kontekst i rozumienie całego repo, planowanie, refaktoryzacje wielu modułów,
krytyczny code review.
**Limit rozmiaru zadań:** `L`.

## Do czego go używać
- Rozpisywanie kart: backlog → ready (DoR) dla wszystkich modeli.
- Zadania `L`: zmiany kontraktu `storage` ↔ `ui`, rozbicie `src/ui.js`.
- Review zadań `deepseek` i `gemini`.

## Dodatkowe DoR
- Zadanie `L` ma w Kontekście krótki plan (kroki) albo link do specyfikacji w `docs/specs/`.

## Dodatkowe DoD (wstawiane automatycznie z `kanban/config.json`)
- Diff przejrzany przez `/code-review` lub drugi model przed `review`.
