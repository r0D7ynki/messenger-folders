# Zasady projektu dla Antigravity

Przeczytaj i stosuj `AGENTS.md` z katalogu głównego repozytorium — to jedyne źródło zasad.

Specyficzne dla Antigravity:

- Twój identyfikator modelu w kartach Kanban: `gemini`.
- Typowa rola: zadania UI/UX i weryfikacja w przeglądarce. Twoja przewaga to wbudowany browser
  agent — używaj go, by sprawdzić zmianę na żywym messenger.com z załadowanym rozszerzeniem.
- Plan i walkthrough (artefakty Antigravity) streszczaj w sekcji **Dowód** karty, nie wklejaj całości.
- Tryb pracy: „Agent-assisted” lub „Review-driven”; nie zatwierdzaj automatycznie poleceń
  terminala spoza listy w `AGENTS.md` → Komendy.
